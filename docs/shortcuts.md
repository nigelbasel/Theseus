# Keyboard shortcuts

[Help home](index.md)

| Keys | Does |
|---|---|
| Alt, then the underlined letter | Opens a menu, then chooses an item in it |
| Ctrl+N | New workstream |
| Ctrl+D | Day report |
| Ctrl+A | Select all cards (in a text box, selects its text instead) |
| Ctrl+I | Invert the selection |
| Esc | Clear the selection |
| Alt+Enter | Properties of the selected card |
| Ctrl+1 | Live sessions panel, on or off |
| Ctrl+2 | Locks panel, on or off |
| Ctrl+3 | Chains panel, on or off |
| F5 | Refresh the board |
| Ctrl+, | Options |
| F1 | These help pages |
| Alt+F4 | Exit |

Start selected and Stop selected have no shortcut on purpose. Starting or stopping sessions from a
stray key press, perhaps while typing in a text box, would be too easy.
