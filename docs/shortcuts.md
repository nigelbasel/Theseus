# Keyboard shortcuts

[Help home](index.md)

| Keys | Does |
|---|---|
| Alt, then the underlined letter | Opens a menu, then chooses an item in it |
| Ctrl+N | New workstream |
| Ctrl+J | Day report |
| Ctrl+A | Select all cards (in a text box, selects its text instead) |
| Ctrl+I | Invert the selection |
| Esc | Clear the selection; in a project's view, first closes Properties when it is open over the view |
| Ctrl+F or / | Find cards |
| F3, Shift+F3 | Next and previous card the search finds |
| Alt+Left | Back to the place you were before |
| Alt+Right | Forward again, after going back |
| Enter | On a project card you have clicked: opens the project's view |
| Alt+Enter | Properties of the selected card |
| Del | Archive the selected cards, on the board |
| Ctrl+L | Focus the lead session of the open project |
| F6, Shift+F6 | Move to the next or previous pane |
| F7 | Live sessions panel, on or off |
| F8 | Locks panel, on or off |
| F9 | Chains panel, on or off |
| Ctrl+1 to Ctrl+8 | Open the project tab of that number |
| Ctrl+9 | Open the last project tab |
| Ctrl+Tab, Ctrl+Shift+Tab | Next and previous project tab, while a project is open |
| F5 | Refresh the board |
| Ctrl+, | Options |
| F1 | These help pages |
| Alt+F4 | Exit |

Start selected and Stop selected have no shortcut on purpose. Starting or stopping sessions from a
stray key press, perhaps while typing in a text box, would be too easy.
